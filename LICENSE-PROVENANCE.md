**Why SPDX and not gnu.org:** `www.gnu.org` was unreachable from the network
this file was retrieved on. SPDX is the Linux Foundation's reference dataset
for licence identification and is the standard machine-readable source.

**Note on formatting:** the SPDX text is semantically identical to the FSF
original but uses unwrapped long lines rather than the FSF's ~70-character hard
wrap. Legal content is unaffected. If you wish to match the FSF's exact
formatting, replace it from `https://www.gnu.org/licenses/agpl-3.0.txt` and
confirm the section structure is unchanged.

**The licence text is deliberately verbatim and must stay that way.** The
copyright notice for this project is *not* prepended to it — the FSF's own
instruction, in the licence's final section, is that the notice belongs in the
program's source files. It appears there, in `NOTICE`, and in `README.md`.
Modifying the licence text risks the licence not applying as intended.
