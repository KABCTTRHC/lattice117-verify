Lattice117

Omni-hardware soak

Runs the same integer arithmetic on this device for as long as you choose, a different generated planning problem every cycle, and checks that it lands on exactly the same numbers as every other device. Everything computes locally; nothing is sent anywhere. Once loaded it works with the network off.

Set up

Web pages cannot read a temperature sensor; no browser exposes one. If you can read it from the device (Android: battery temperature in Settings or termux-battery-status; laptops: the OS sensor tool), enter it here and the record marks it as entered by the operator. For measured temperature every cycle, use the native soak (omni_soak) on Linux, Android (Termux), Pine64 or a Chromebook.

Ready. Plug the device in and keep this tab in front: a hidden tab is slowed down by the browser, and the record says how long it was hidden.
