Privacy policy

Lattice117 Schedule Check · Brierley Sovereign Group Ltd · Last updated 26 September 2026

No data leaves your machine. No telemetry is collected. This add-in makes no network requests of any kind while it runs. Your workbook, your schedules, the names in them and the results of any check are read, computed and displayed entirely inside Excel on your own device.

What we collect

Nothing. We operate no server, no database and no analytics for this add-in. There is no account to create and nothing to log into. We could not identify a user of this add-in if we were asked to.

How it works, and why that matters

The verification engine is a 21 KB WebAssembly module that runs inside Excel's own task-pane process. It opens no sockets. This is a structural property of the software rather than a policy we are asking you to trust: disconnect from the network entirely and the add-in still works, which is the simplest way to confirm it.

The one-off files the add-in needs — the page, the engine — are served from GitHub Pages when the pane first opens, exactly as any web page is. Those requests carry no information about your workbook.

Google Sheets

The same add-in is published for Google Sheets, and the architecture there differs in one respect that we would rather state than gloss over.

The sidebar page itself is served by Google. Apps Script delivers it from a sandboxed googleusercontent.com iframe each time you open it. That is Google serving the page — not us. We operate no server and receive nothing from it.

Everything after that is local. Once the sidebar has loaded, reading the grid, the Q16.16 fixed-point evaluation in WebAssembly, the rest and break arithmetic, the SHA-256 digest and the licence check all happen inside that iframe on your own machine. Zero network requests are made to Brierley Sovereign Group Ltd at any point. The 21 KB engine is inlined into the sidebar, so there is nothing to download either.

The add-on holds exactly one OAuth scope, spreadsheets.currentonly, which permits access to the single spreadsheet you have open and to no other file in your Drive. It holds no scope permitting external requests, and its server-side code contains no UrlFetchApp — a test in the repository asserts this on every commit rather than leaving it as a claim.

One honest difference from Excel: the Excel task pane is served from GitHub Pages with a service worker, so it keeps working with the network disconnected. The Sheets sidebar is delivered by Google each time it opens, so it needs a connection to open — but not to compute. Both are equally local once running.

Licence keys

If you buy a Standard or Pro licence, payment is handled by Stripe, who process your payment details under their own privacy policy. We receive your email address so we can send you a licence key, and we keep it only to issue and renew that key.

The key itself is a short signed token. It is verified inside the add-in by public-key signature and stored in your browser's local storage on your own device. Checking it involves no network request, so we do not know when, where or how often you use the product.
